Drop it in

Full styles and the scroll trigger live in snippets/squiggly-arrow.html — copy that file wholesale and it works as-is.

Dials

Everything is a CSS custom property on .squiggly-arrow, so a theme override is one rule.

  • --sa-color — line colour. Defaults to the site's green; currentColor also works if you want it to inherit from surrounding text.
  • --sa-width — overall width. Height follows the 11:6 aspect ratio automatically.
  • --sa-stroke — line thickness, in viewBox units (5 reads like a marker at 220px wide).
  • --sa-speed — how long the squiggle takes to draw. The arrowhead lands at 82% of that.
  • --sa-delay — pause after the section enters the viewport.
  • snippets/squiggly-arrow.html — standalone HTML, CSS and scroll trigger for any site builder.
  • src/components/ui/SquigglyArrow.jsx — the same arrow as a React component with color, width, strokeWidth, duration, drift and flip props.

Behaviour worth knowing

  • The draw fires once, when 40% of the arrow is in view — so it isn't already finished by the time a visitor scrolls down to it.
  • Under prefers-reduced-motion the finished arrow renders instantly with no drawing and no drift.
  • Below 768px the cards stack under the copy, so the snippet flips the arrow vertically to point down-right instead. Set flip or drop that media query if your layout differs.
  • The SVG carries an aria-label; if the arrow is purely decorative next to a heading that already says "take a look below", swap it for aria-hidden="true".
